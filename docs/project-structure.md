# Project Structure

Concrete mechanics behind the summary in `CLAUDE.md`. React 18 + TS + Vite 4 + MUI v5, Thai UI copy.

## Bootstrap order

`src/main.tsx` → [`src/AppRoot.tsx`](../src/AppRoot.tsx) mounts, in order:
`AuthProvider` (OIDC) → `ReduxProvider` → `QueryClientProvider` → `App`.

`AppRoot` also: configures dayjs globally (Thai locale, `buddhistEra` plugin, tz fixed to
`Asia/Bangkok`), sets React Query defaults (`retry: 3`, `retryDelay: 5000`, `staleTime: 5min`).

## Env / config

**Not** `import.meta.env`. `vite.config.ts` collects every `VITE_*` for the build mode →
writes `public/configuration.js` → sets frozen `window.__CONST__ENV__` →
[`src/Const.ts`](../src/Const.ts) destructures it into typed exports (`API_URL`, `APIGW_URL`,
`DOCSTORAGE_API_URL`, `API_CLAIM_FUND_URL`, `OCR_API_URL`, `SSO_CONFIG`, `APP_INFO`,
`PermissionList`, …). Always import config from `Const.ts`.

New env var checklist: add to every `.env*` → declare in `Const.d.ts` → export from `Const.ts`.

## Routing — two separate registries, kept in sync manually

1. **`src/app/routes/Routes.tsx`** — the `RouteMapType[]` array. Each entry becomes a
   react-router `RouteObject` via `createRouteObject()` in
   [`AuthRoutes.tsx`](../src/app/routes/AuthRoutes.tsx), which moves `title` / `permissions` /
   `condition` / `getTitle` / `icon` / `hideAppBar` / `hideAsideMenu` into `handle`.
   `src/App.tsx` assembles: `AuthRoutes` (callbacks, `/unauthorized`) + `Routes` array under
   `<Layout />` + public routes (`/slip/:id`, `/survey/*`) under `<LayoutPublic />` + `*` →
   `/not-found`. **Adding a page = append one entry here.** See [routes.md](routes.md) for the
   full current list.

2. **`src/app/routes/ASideMenuList.tsx`** — the sidebar drawer, hand-written JSX
   (`<ParentMenu>` / `<MenuItem>`), **not generated from `Routes.tsx`**. Adding a page to the
   menu is a *separate* manual step from adding the route. `ParentMenu`/`MenuItem` live in
   `src/app/layout/components/` (re-exported via `src/app/layout/index.ts`); `icon` accepts
   either a Material ligature string (`"local_hospital"`) or a JSX icon element.

   ⚠️ Gotcha hit in this repo (see [routes.md](routes.md)): if the same page component is
   registered at two different paths (e.g. as both a parent's `index` route and an explicit
   child path), **relative `navigate("child/path")` calls resolve differently depending on
   which URL the user is actually on**, and can silently 404 by duplicating a path segment.
   Prefer one canonical path per page; use `<Navigate to="..." replace />` for aliases, not a
   second copy of the element.

3. **`PermissionList`** ([`Const.ts:74`](../src/Const.ts)) currently has only one member,
   `none`. Every route/menu entry passes `permissions: []`, which `checkPermissions()`
   (`src/app/modules/_auth/auth.ts`) treats as "always allowed" — i.e. **route guarding is not
   actually enforced anywhere yet**, it's wired up but toothless until real permissions are
   added to the enum.

## Auth (OIDC)

`oidc-client-ts` — `UserManager` created in `AppRoot.tsx`, tokens in `localStorage`, silent
renew on. [`AuthProvider.tsx`](../src/app/modules/_auth/components/AuthProvider.tsx) registers
**one** `axios.interceptors.request` that attaches `Authorization: Bearer <token>` to **every**
axios call app-wide — API client classes just take the bare `axios` instance and rely on this
interceptor; they never handle auth themselves. `useAuth()` exposes `permissions`/`roles`.

## Data layer

NSwag generates client classes into `src/app/api/*.client.ts` (gitignored regen target is root
`./api.client.ts`; the per-domain `*.client.ts` files under `src/app/api/` are committed and
regenerated by running `npm run codegen` against each service's swagger). Each has a
hand-written sibling `src/app/api/<name>Api.ts` that:

- instantiates the client **once** at module scope: `const xClient = new XClient(API_URL, axios)`
- declares one `const xQueryKey = ["x"]` per endpoint near the top
- exports `useGetX(...)` query hooks: `useQuery([xQueryKey, ...params], () => xClient.getX(...), { enabled: ..., refetchOnWindowFocus: false })`
- exports `useXMutation(onSuccessCallback?, onErrorCallback?)` hooks: the `*ServiceResponse`
  envelope's `isSuccess === false` routes to `onErrorCallback` (not react-query's `onError`,
  which only fires on transport/HTTP failure)

Components **only** call these wrapper hooks — never the client classes or axios directly. Full
inventory: [api-inventory.md](api-inventory.md).

**Hard rule** (see [CLAUDE.md](../CLAUDE.md#architecture)): check `api-inventory.md` before
adding a new hook — the endpoint may already be wrapped. Never hand-edit a `*.client.ts` file;
it's pure NSwag output and gets overwritten wholesale by `npm run codegen`. Fix the backend
contract and regenerate instead. The sibling `*Api.ts` wrapper (no `.client`) is hand-written by
design — that's where new hooks go.

Company API convention: **GET and POST only**, no PUT/PATCH/DELETE. Mutations POST to an action
path (`{id}/update`, `{id}/delete`, `/claim/decision/approve`, …).

Dates cross the wire as strings but generated DTOs type them `dayjs.Dayjs` (NSwag
`dateTimeType: DayJS`). Format with `formatDateString(value?.toString(), "DD/MM/BBBB")` from
[`src/app/functionHelpers.ts`](../src/app/functionHelpers.ts) (`.toString()` first — `Dayjs`
isn't a plain string). `BBBB` = Buddhist year.

## State (Redux)

[`src/redux/rootReducer.ts`](../src/redux/rootReducer.ts) combines one slice per feature module.
Only `layout` is `redux-persist`-wrapped; everything else is in-memory and resets on reload.
Typed hooks: `useAppSelector` / `useAppDispatch` from `src/redux/hook.ts` (re-exported via
`src/redux/index.ts`). Each slice: `modules/<Feature>/store/<feature>Slice.ts`, exports its
actions + a `<feature>Selector`.

⚠️ Known trap: `claimConsider.filledItems` (expense line items) is global state shared across
whatever page mounts `ClaimConsider`'s `ExpenseRecords`/`useClaimExpenseDetailHook` — two pages
open at once, or a page that shouldn't touch it, can clobber each other. When adding a new
module, prefer **local state scoped to that page's component tree** unless the state genuinely
needs to survive navigation (like a list page's rows standing in for a query cache) — see
`BillingClaim`'s slice for the deliberate split (`rows` in redux, everything else local).

## Module layout (fixed shape)

```
src/app/modules/<Feature>/
├── pages/        route entry components (what Routes.tsx points `element` at)
├── components/   presentational + feature widgets
├── hooks/        feature logic — usually wraps API hooks + Formik
└── store/        redux slice (only if the module needs cross-page/cross-step state)
```

Cross-cutting code: `modules/_common` (barrel `index.ts` re-exports `commonFunctions`,
`commonValidators`, `sweetAlert`, `types`, and `components/` — but **not everything under
`components/` is in the barrel**, `CustomComponent/*` and `ClaimAgent/*` need deep imports, e.g.
`import CustomPaper from ".../_common/components/CustomComponent/CustomPaper"`) and
`modules/_auth`. Shared helpers also in `src/app/functionHelpers.ts`,
`src/app/deathBenefitHelpers.ts`, `src/app/ocrCompareHelpers.ts`.

## Forms & tables

Formik + `zod` via `zod-formik-adapter` (older modules use a hand-written `validate` function
instead of zod — both patterns coexist, e.g. `ClaimConsider`/`BillingClaim` use hand-written
`validate`). MUI wrappers: `_common/components/CustomFormik/*` (`FormikTextField`,
`FormikDropdown`, `FormikDatePicker`, …). Tables: `mui-datatables` via
`_common/components/DataTable/StandardDataTable.tsx` + `cellAlignOptions()` /
`defaultOptionStandardDataTable` / `smallSizeFooter` from `functionHelpers.ts`.

## Code style

CRLF line endings (enforced), 4-space indent, printWidth 120, double quotes, `eslint --max-warnings 0`.
Repo currently has ~4500 *pre-existing* lint warnings outside anything touched this session
(mostly CRLF drift in old files) — don't let a repo-wide `npm run lint` scare you; scope it to
the files you touched: `npx eslint <paths> --max-warnings 0`, and `npx eslint <paths> --fix` to
clean up CRLF/prettier automatically before committing.
