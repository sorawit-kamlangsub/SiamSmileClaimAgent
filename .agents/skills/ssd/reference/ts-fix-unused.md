
# SSD TypeScript Fix Unused — แก้ error TS6133 / TS6196 อัตโนมัติ

## บริบท

tsconfig ของ SSD เปิด `noUnusedLocals` และ `noUnusedParameters` ทำให้ build fail เมื่อมีตัวแปรหรือ parameter ที่ไม่ได้ใช้ ปัญหานี้เกิดบ่อยใน NSwag-generated files (`*.client.ts`) ซึ่งเราไม่ควรแก้เนื้อหาตรงๆ

**Error codes ที่ต้องจัดการ:**
- `TS6133` — 'X' is declared but its value is never read
- `TS6196` — 'X' is declared but never used

## กฎหลัก

1. **NSwag generated files** (`src/app/api/*.client.ts`) — ใช้ `// @ts-nocheck` ที่บรรทัดแรก เพราะ regenerate ทุกครั้งที่รัน codegen
2. **Manual code files** — ใช้ `// @ts-ignore` บรรทัดก่อน error แต่ละ error
3. ห้ามแก้ไขเนื้อหาใน NSwag generated files โดยตรง — จะถูก overwrite ตอน regenerate
4. ห้ามเปลี่ยน `tsconfig.json` (`noUnusedLocals` / `noUnusedParameters`) — เป็น SSD standard
5. รัน build อีกครั้งหลังแก้ทุกครั้งเพื่อยืนยันว่าผ่าน

## ขั้นตอนที่ 2: จำแนก Files

แบ่งไฟล์ออกเป็น 2 กลุ่ม:

**กลุ่ม A — NSwag Generated** (ใช้ `// @ts-nocheck`):
- ไฟล์อยู่ใน `src/app/api/` และชื่อลงท้ายด้วย `.client.ts`
- หรือบรรทัดแรกของไฟล์มี `// <auto-generated` หรือ `/* eslint-disable */`

**กลุ่ม B — Manual Code** (ใช้ `// @ts-ignore` ทีละ error):
- ไฟล์อื่นๆ ทั้งหมด

---

## ขั้นตอนที่ 3: แก้ไข

### กลุ่ม A — NSwag Generated Files

อ่านไฟล์ แล้ว **เพิ่ม `// @ts-nocheck` เป็นบรรทัดแรกสุด**:

```typescript
// @ts-nocheck
// <auto-generated/>
//...
```

> ทำแค่ครั้งเดียวต่อไฟล์ — ครอบคลุมทุก error ในไฟล์นั้นทั้งหมด

### กลุ่ม B — Manual Code

สำหรับแต่ละ error ใน manual code — เพิ่ม `// @ts-ignore` **ก่อนบรรทัดที่ error**:

```typescript
// ก่อนแก้:
const _responseText = response.data;

// หลังแก้:
// @ts-ignore TS6133: unused variable — required by function signature
const _responseText = response.data;
```

> เรียง errors จาก line สูงไปต่ำเมื่อแก้ในไฟล์เดียวกัน เพื่อให้ line numbers ไม่เลื่อน

## ตัวอย่าง

### NSwag generated file (กลุ่ม A)

```
src/app/api/lineoapasadmin.client.ts:1697:19 - error TS6133: '_responseText' is declared but its value is never read.
src/app/api/lineoapasadmin.client.ts:2103:19 - error TS6133: '_responseText' is declared but its value is never read.
```

**แก้:** เพิ่ม `// @ts-nocheck` บรรทัดแรกของ `lineoapasadmin.client.ts` — แก้ทั้งไฟล์ใน 1 บรรทัด

### Manual file (กลุ่ม B)

```
src/app/modules/Order/components/OrderTable.tsx:45:9 - error TS6133: 'index' is declared but its value is never read.
```

**แก้:** เพิ่ม `// @ts-ignore` บรรทัดที่ 44 (ก่อน error)

## ข้อควรระวัง

| สถานการณ์ | การจัดการ |
|----------|----------|
| ไฟล์ generated มี `// @ts-nocheck` อยู่แล้ว | ข้ามไป ไม่ต้องทำซ้ำ |
| Error เดียวกันหลาย line ใน manual file | เพิ่ม `// @ts-ignore` ทุก line แยกกัน |
| ตัวแปรที่ควรลบออกจริงๆ (ไม่ใช่ generated) | ลบทิ้งแทนการ ignore — อย่า ignore code ที่ dead จริงๆ |
| Parameter ที่ใช้ใน interface/callback | prefix ด้วย `_` เช่น `_event` แทน `// @ts-ignore` |
